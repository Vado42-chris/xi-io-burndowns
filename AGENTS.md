# Worker entry

This repository is a public publication surface for finished burndown reports.

## Default behavior

- Read and explain public repository content freely.
- Propose changes only against public-safe material.
- Treat every report candidate as **not publication-qualified** until the publication boundary is satisfied.
- Do not request, import, infer, or reconstruct private source material, private framework internals, secrets, private repository topology, private customer/case facts, or unpublished operational evidence.
- Do not treat repository visibility as reuse, contribution, or redistribution permission.

## Before adding or materially changing a report

1. Identify the report's public source/provenance class.
2. Confirm the report is a finished projection, not a private/draft evidence bundle.
3. Check direct identifiers and indirect reconstruction risk.
4. Check that proprietary implementation details, internal scoring/selection heuristics, private topology, and unpublished framework mechanics are absent.
5. Check rights/licensing of all included text, code, images, datasets, and third-party material.
6. Require an independent public-release review for private-derived reports.
7. Bind approval to the exact candidate generation; material changes invalidate prior approval.

If any required answer is unknown, the report stays unpublished.

## Allowed public report content

Use the minimum sufficient public representation: generalized failure class, outcome, bounded method, known-answer or hostile-test result, limitations, and community-useful lesson.

## Never publish here

Secrets or credentials; private identities or addresses; raw private correspondence/evidence; private file/object/message IDs; private hashes or locators; distinctive combinations of dates/counts/events that re-identify a source; private repository or cross-project topology; unpublished framework source or implementation; proprietary decision/scoring heuristics; private prompts or internal worker packets; material whose rights to publish are unresolved.
