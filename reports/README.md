# Reports

Only **publication-qualified finished burndown reports** belong in this directory.

A report is not ready merely because names were removed or the originating work is complete. Follow `../docs/publication-boundary.md` and the worker entry contract before adding a report.

Recommended public report shape:

1. problem / failure class;
2. public-safe context;
3. observed consequence;
4. bounded method or synthetic reproduction;
5. remediation / lesson;
6. limitations and unknowns;
7. public-safe qualification statement.

Do not include the private source bundle, hidden analysis, internal issue/topology map, worker packet, private evidence references, proprietary scoring/routing machinery, or unresolved third-party material.

No real report is currently qualified for publication.
